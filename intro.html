产品介绍 · v1.0.0

代码审计，本该在浏览器里完成

CodeAudit Lite 是一个纯前端代码审计组件：把代码拖进浏览器，即得 P0-P3 四级分级的安全与质量报告。零依赖、零后端、零上传—— 为内网环境、合规敏感场景与"只想快速看一眼"的时刻而生。

Features · 功能说明

一个页面，覆盖审计闭环

从载入代码到导出报告，全部在单个页面内完成。每个能力都可以独立使用，也可以组合成完整流水线。

多语言规则扫描

37 条静态规则，覆盖 JS/TS、Python、Go、Java、SQL 与通用文本。按扩展名自动识别语言，命中对应规则子集。

凭据泄露检测

云 AK/SK、数据库连接串、GitHub PAT、JWT、私钥块、Bearer 令牌——命中即 P0，按"已泄露"处置。

占位符智能去伪

secret 类规则内置去伪：<TOKEN>、${ENV_VAR}、全大写蛇形占位不误报，让 P0 数量可信。

健康评分量化

加权扣分制（P0 -2.5 起），按 2000 行基线归一化，产出 1-10 分健康分。交付质量一眼可比。

分级过滤与检索

点击严重度卡片即过滤对应级别；关键词实时过滤规则 ID、文件路径、代码片段。千条发现也不迷路。

Markdown 报告导出

结论先行 + 指标表 + 分级明细，一键导出 .md。可直接贴进 PR 描述、周报或缺陷跟踪系统。

Core · 核心特性

三个设计决策，定义这个组件

🔒 代码不出浏览器

基于 File API 在本地内存中分析，无网络请求、无后端、无遥测。关闭页面即销毁全部数据。

  • 适配内网 / 隔离区 / 合规敏感环境
  • 无部署成本：静态文件，任何静态托管可放
  • 审前无需审批数据外发

🎯 分级不是为了好看，是为了决策

P0-P3 对应明确的处置语义，分级体系源自业界通用代码审计方法论。

  • P0 阻断 可利用缺陷 · 修复前禁止合入
  • P1 严重 安全边界劣化 · 本迭代修复
  • P2 建议 质量隐患 · 排期优化
  • P3 风格 卫生问题 · 顺手清理

🧩 零依赖，可嵌可拆

engine.js 与 UI 完全分离，引擎可脱离页面单独嵌入任何前端工程。

  • 引擎暴露 scanFile / healthScore / RULES 三个接口
  • CommonJS 与浏览器全局双导出
  • 规则库纯数据结构，可按团队规范增删

⚖️ 证据先于结论

每条发现都带规则 ID、精确行号、代码摘录与修复方向，可追溯可复核。

  • 注释行不误报（结构规则跳过注释）
  • 纯字面量赋值豁免（如 innerHTML = "静态串"）
  • 报告声明静态扫描边界，不越权下结论
Scenarios · 使用场景

谁在用它，什么时候用

1

合入前的最后自查

PR 提交前把变更文件拖一遍：P0 清零再发，凭据误提交在源头拦截，而不是事后轮换。

适用：开发工程师 · Code Review 提交方
2

接手存量代码的第一摸底

接手陌生项目，先全量拖入扫一遍。健康评分 + P0/P1 分布给出风险底数，接手评估有据可依。

适用：新任维护者 · 技术尽调
3

内网 / 合规环境的轻量审计

代码严禁外发，商业 SAST 用不起或走不完流程。纯本地静态文件，即开即用，审完即走。

适用：内网研发 · 安全合规岗
4

新人安全意识训练

规则库即教材：37 条规则每条都写明"为什么错 + 怎么改"。拿自己写的历史代码扫一遍，比读十篇文章有效。

适用：团队安全培训 · 新人 onboarding
边界声明：CodeAudit Lite 是静态规则扫描，覆盖已知模式，不能替代人工深度审查、渗透测试与完整 SAST 流水线。P0 清零是合入底线，不是安全承诺。
Quick Start · 快速上手

三步出报告

打开工具页

无需安装、无需注册，浏览器直接打开 index.html（或工具站上的「打开工具」入口）。

拖入代码

把单个文件、多选文件或整个文件夹拖进虚线区域。依赖目录与二进制自动跳过。

# 适合拖入的典型范围
src/            # 业务源码目录
scripts/        # 运维 / 构建脚本
config.yaml     # 配置文件（凭据高发区）

# 会被自动跳过
node_modules/  .git/  dist/  vendor/  *.png  *.exe ...

读报告、做处置、导出留档

先看评分环与结论语：有 P0 先停下修；无 P0 按分级排期。处置完可一键导出 Markdown 贴进 PR 或周报。

| P0 / P1 / P2 / P3 | 2 / 3 / 7 / 4 |

API · 引擎嵌入

在自己的工程里调用引擎

engine.js 与 UI 解耦，可嵌入任意前端项目做自定义审计流。

<script src="engine.js"></script>
<script>
const findings = CodeAudit.scanFile('config.yaml', fileText);
// → [{ ruleId:'UNIV-03', severity:'P0', line:12, excerpt:'...', fix:'...' }]

const score = CodeAudit.healthScore(findings, lineCount);
// → 1..10 的健康评分（加权扣分 + 2000 行归一化）

const rules  = CodeAudit.RULES;  // 37 条规则元数据，可按团队规范增删
</script>
Scoring · 评分权重

健康评分怎么算

级别单条扣分处置语义
P0 阻断-2.5可利用缺陷 / 凭据泄露 · 修复前禁止合入
P1 严重-1.5安全边界劣化 · 本迭代内修复
P2 建议-0.5质量隐患 · 排期优化
P3 风格-0.1风格卫生 · 顺手清理

总扣分按 2000 行基线归一化（代码量越大容忍度越高），最终得分 clamp 在 1-10。≥8 绿、6-7.9 黄、<6 红。
