CodeAudit Lite 的版本沿革。语义化版本：破坏性变更升主版本，规则/功能新增升次版本，修复升修订号。

v1.0.02026-11-02当前版本
  • 首发：37 条静态规则 × P0-P3 四级分级，覆盖 JS/TS · Python · Go · Java · SQL · 通用文本。
  • 核心能力：凭据泄露检测（AK/SK · 数据库连接串 · PAT · JWT · 私钥块）、注入类（SQL 拼接 / 命令拼接 / XSS / 动态执行）、反序列化（pickle / yaml.load）、并发与可靠性（无超时 HTTP 客户端 / 吞异常 / 长 sleep 轮询）。
  • 占位符去伪：secret 类规则自动识别 <TOKEN> / ${ENV_VAR} / 全大写蛇形占位，杜绝"假凭据"误报。
  • 健康评分：加权扣分制（P0 -2.5 / P1 -1.5 / P2 -0.5 / P3 -0.1），2000 行基线归一化，1-10 分量化交付质量。
  • 交互：拖拽文件/文件夹载入（最多 300 个、单文件 ≤2MB、二进制与依赖目录自动跳过）、严重度卡片过滤、关键词实时过滤、Markdown 报告一键导出。
  • 隐私：纯浏览器 File API 本地分析，无网络请求、无后端、无遥测。
